# Скрипты управления складами

## Обзор
Данная директория содержит скрипты для управления складами в системе BaseLinker to Wix. Скрипты обеспечивают безопасное переименование складов с автоматическим обновлением всех связанных таблиц и кода.

## Файлы

### `warehouse_manager.py`
Универсальный менеджер складов с расширенным функционалом.

**Возможности:**
- Переименование складов с обновлением всех связанных таблиц
- Предварительный просмотр изменений (dry-run режим)
- Статистика по складам во всех таблицах
- Список всех складов в системе
- Детальная информация о конкретном складе

**Использование:**
```bash
# Список всех складов
python scripts/warehouse_manager.py list

# Информация о складе
python scripts/warehouse_manager.py info "Основной"

# Предварительный просмотр переименования
python scripts/warehouse_manager.py rename "Основной" "Новый" --dry-run

# Переименование склада
python scripts/warehouse_manager.py rename "Основной" "Новый"
```

### `rename_warehouse.py`
Специализированный скрипт для переименования складов.

**Возможности:**
- Простое переименование с подтверждением
- Обновление всех связанных таблиц
- Автоматическое обновление кода

**Использование:**
```bash
python scripts/rename_warehouse.py "Основной" "Новый"
```

## Поддерживаемые таблицы

Скрипты автоматически обновляют следующие таблицы:

| Таблица | Описание | Поля для обновления |
|---------|----------|---------------------|
| `stock` | Остатки товаров на складах | `warehouse` |
| `sale` | Логи продаж (списаний) | `warehouse` |
| `transfer` | Логи перемещений между складами | `source`, `destination` |
| `operation` | Операции с товарами | `warehouse_id`, `target_warehouse_id` |
| `pending_stock_operation` | Ожидающие операции синхронизации | `warehouse` |

## Интеграция с Makefile

Система интегрирована с Makefile проекта для удобного использования:

```bash
# Список всех складов
make warehouse-list

# Информация о складе
make warehouse-info WAREHOUSE=Основной

# Предварительный просмотр переименования
make warehouse-rename-dry-run OLD_NAME=Основной NEW_NAME=Новый

# Переименование склада
make warehouse-rename OLD_NAME=Основной NEW_NAME=Новый
```

## Безопасность

### Подтверждение операций
Все операции переименования требуют подтверждения пользователя:
```
ВНИМАНИЕ: Вы собираетесь переименовать склад 'Основной' в 'Новый'
Это действие затронет все связанные таблицы и не может быть отменено автоматически.
Продолжить? (y/N):
```

### Предварительный просмотр
Используйте флаг `--dry-run` для анализа изменений без применения:
```bash
python scripts/warehouse_manager.py rename "Основной" "Новый" --dry-run
```

### Автоматическое резервное копирование
Рекомендуется создать резервную копию базы данных перед выполнением операций:
```bash
# Создание резервной копии
docker compose exec postgres pg_dump -U postgres baselinker_to_wix > backup_$(date +%Y%m%d_%H%M%S).sql
```

## Логирование

Все операции логируются с детальной информацией:
- Количество обновленных записей в каждой таблице
- Общее количество изменений
- Ошибки и предупреждения
- Время выполнения операций

## Требования

- Python 3.8+
- SQLModel
- Доступ к базе данных PostgreSQL
- Права на запись в файлы проекта (для обновления кода)

## Примеры использования

### Переименование склада "Основной" в "Новый"

1. **Предварительный анализ:**
   ```bash
   make warehouse-info WAREHOUSE=Основной
   make warehouse-rename-dry-run OLD_NAME=Основной NEW_NAME=Новый
   ```

2. **Выполнение переименования:**
   ```bash
   make warehouse-rename OLD_NAME=Основной NEW_NAME=Новый
   ```

3. **Проверка результата:**
   ```bash
   make warehouse-info WAREHOUSE=Основной
   make warehouse-list
   ```

### Анализ системы складов

```bash
# Получить общую картину
make warehouse-list

# Детальная информация по каждому складу
for warehouse in $(docker compose exec app python scripts/warehouse_manager.py list | grep "^-" | cut -d' ' -f3); do
    echo "=== Склад: $warehouse ==="
    make warehouse-info WAREHOUSE="$warehouse"
    echo
done
```

## Устранение неполадок

### Ошибка доступа к файлам
```bash
# Проверить права доступа
ls -la scripts/

# Исправить права доступа
chmod +x scripts/*.py
```

### Ошибки базы данных
```bash
# Проверить подключение к БД
docker compose exec app python -c "from app.database import SessionLocal; print('OK')"

# Проверить логи
make logs-postgres
```

### Проблемы с кодом
```bash
# Проверить синтаксис Python
python -m py_compile scripts/warehouse_manager.py

# Проверить импорты
python -c "import sys; sys.path.insert(0, '.'); from scripts.warehouse_manager import WarehouseManager; print('OK')"
```

## Поддержка

При возникновении проблем:
1. Проверьте логи выполнения скрипта
2. Убедитесь в корректности названий складов
3. Проверьте права доступа к файлам и базе данных
4. Создайте резервную копию перед повторным выполнением
